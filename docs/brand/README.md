# Brand files

The Ci sto logo as files, for Figma, slides and chats. The source is [components/Logo.tsx](../../components/Logo.tsx). These files have the same drawing, without the animation.

The colours come from [docs/design-system.md](../design-system.md). Only Max changes these files.

## Logo

A wordmark: a hand makes the "C" with an OK gesture, followed by "i STO".

| File | Colour | Use |
|---|---|---|
| `ci-sto-logo-blue.svg`, `.png` | blue `#2347FF` | On light backgrounds |
| `ci-sto-logo-lime.svg`, `.png` | lime `#CBEF4A` | On dark backgrounds |
| `ci-sto-logo-white.svg`, `.png` | white `#FFFFFF` | One-colour version, for example on the blue background |
| `ci-sto-logo-ink.svg`, `.png` | ink `#16131D` | One-colour version for light backgrounds |

## Hand mark

The hand alone, without "i STO". It comes in the same four colours: `ci-sto-mark-blue`, `ci-sto-mark-lime`, `ci-sto-mark-white` and `ci-sto-mark-ink`, each as `.svg` and `.png`.

## WhatsApp group icon

Square images, 1080 × 1080 px. There is space around the logo, so the round crop of WhatsApp does not cut it.

| File | What |
|---|---|
| `whatsapp/ci-sto-whatsapp-blue.svg`, `.png` | White logo on blue |
| `whatsapp/ci-sto-whatsapp-white.svg`, `.png` | Blue logo on white |
| `whatsapp/ci-sto-whatsapp-ink.svg`, `.png` | Lime logo on ink |

## Which format to use

- **SVG** for Figma and for anything that must scale. Drag the file into Figma.
- **PNG** for slides, documents and chats. The logo PNGs are 2050 × 1625 px and the hand mark PNGs are 1200 × 1600 px. They have a transparent background. The WhatsApp icons have a solid background.
