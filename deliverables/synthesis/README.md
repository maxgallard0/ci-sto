# Synthesis

This folder will hold `synthesis.md`: one merged version of all team deliverables.

- It is made after the deliverables are merged into `main`, with [skills/synthesis/SKILL.md](../../skills/synthesis/SKILL.md).
- It gives the final story IDs (`STU-01`, `ORG-01`, `PAR-01`) and maps them to the original IDs.
- It shows conflicts, gaps and new ideas. It does not decide them. The team decides.
- Only Max changes this folder, or someone Max asks.
